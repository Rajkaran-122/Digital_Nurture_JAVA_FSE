# Bootstrap 5 Masterclass

This repository contains the solutions to the Bootstrap 5 exercises, showcasing responsive design patterns and pre-built components.

## Architecture

- `exercises/`: Directory housing the isolated component implementations.
  - `01-04-setup-grid.html`: Covers basic grid scaffolding, containers, and responsive breakpoints.
  - `05-08-align-flex-forms.html`: Demonstrates Flexbox alignment utilities and modern form controls.
  - `09-12-components.html`: Showcases advanced UI elements like Navbars, Cards, Modals, and Carousels.
  - `13-16-utilities.html`: Focuses on Bootstrap utility classes for spacing, typography, and display toggling.
  - `17-18-icons-plugins.html`: Integrates Bootstrap Icons and external plugins.
- `exercise_19_sass/`: Demonstrates advanced framework customization via SCSS variables.
- `index.html`: Centralized dashboard for navigating through the Bootstrap modules.

## Implementation Notes

- **Mobile-First Design**: Ensures all layouts naturally scale from mobile devices up to large desktop monitors utilizing Bootstrap's responsive tier system.
- **Component Reusability**: Leverages Bootstrap's native component classes to rapidly construct complex UIs without writing custom CSS.
- **Custom SCSS Theme**: Overrides Bootstrap's default `$primary` and radius variables to inject a custom Neo-Brutalist Black & White aesthetic across the entire framework.
