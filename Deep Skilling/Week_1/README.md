## 🔗 Quick Navigation

Explore each module's detailed documentation and hands-on exercises below:

1. 🏛️ [**Engineering Concepts**](Engineering%20concepts/README.md)
   - **Focus:** Data Structures (Lists, Maps), Algorithms (Sorting, Searching), and advanced Design Patterns (Singleton, Factory, Builder, Observer, MVC).
   
2. 🔀 [**GIT**](GIT/README.md)
   - **Focus:** Version control fundamentals, repository initialization, branching (`git checkout -b`), merging, and conflict resolution.
   
3. 🧪 [**JUnit, Mockito and SL4J**](JUnit,%20Mockito%20and%20SL4J/README.md)
   - **Focus:** Writing robust Unit Tests, mocking dependencies with Mockito, and implementing standard application logging with SLF4J.
   
4. 💾 [**PLSQL**](PLSQL/README.md)
   - **Focus:** Relational database schema creation, constraints, procedural SQL (PL/SQL), and data manipulation.
