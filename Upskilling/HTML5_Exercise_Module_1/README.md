# HTML5 Masterclass

This repository contains the solutions to the HTML5 exercises, focusing on semantic structure, forms, and web APIs. 

## Architecture

- `exercises/`: Directory containing isolated HTML solutions grouped by concept.
  - `01-03-basics.html`: Covers semantic layout, media elements, and basic structuring.
  - `04-06-forms.html`: Demonstrates advanced HTML5 form inputs, validation, and layout.
  - `07-10-apis.html`: Implements modern Web APIs including Geolocation, Local Storage, Web Workers, and Canvas.
- `index.html`: Centralized dashboard linking to all exercise modules.
- `docs/`: Reference documentation and guidelines.

## Implementation Notes

- **Semantic HTML**: Strict adherence to HTML5 elements (`<article>`, `<section>`, `<aside>`) to ensure accessibility and SEO compliance.
- **Form Validation**: Utilizes native HTML5 validation constraints to minimize required JavaScript boilerplate.
- **Web APIs**: Demonstrates modern browser capabilities, ensuring responsive UI feedback when interacting with local storage or asynchronous workers.
