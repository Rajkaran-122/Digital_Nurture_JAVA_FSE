# CSS3 Masterclass

This repository contains the solutions to the CSS3 exercises, implementing a custom Neo-Brutalist design system.

## Architecture

- `exercises/`: Directory containing isolated visual solutions grouped by layout methodology.
  - `01-03-selectors.html`: Demonstrates advanced combinators and pseudo-classes.
  - `04-07-styling.html`: Focuses on typography, color theory, backgrounds, and box model implementation.
  - `08-11-layout.html`: Showcases modern layout techniques utilizing Flexbox and CSS Grid.
- `assets/css/styles.css`: The central stylesheet containing reusable utility classes and global reset rules.
- `index.html`: Centralized dashboard for navigating through the stylized modules.

## Implementation Notes

- **Design System**: Implements a striking Black & White Neo-Brutalist aesthetic featuring sharp edges, pure black borders, and high contrast.
- **Responsive Layout**: Heavy utilization of CSS Grid for two-dimensional scaffolding and Flexbox for one-dimensional alignment, ensuring fluid responsiveness across devices.
- **Modularity**: Adheres to DRY principles by separating styling logic into centralized assets rather than relying on inline styles.
