1. Setting Up Bootstrap 5

Exercise 1.1: Basic HTML & CDN

The CSS and JS bundles for Bootstrap 5 have been included in this page via the jsDelivr CDN. You can find the <link> tag in the <head> and the <script> tag at the bottom of the <body>.

Exercise 1.2: NPM or Download Setup

NPM Setup: To set up via npm, you run npm install bootstrap in your terminal. This downloads the source Sass files and compiled CSS/JS into the node_modules/bootstrap directory. (See Exercise 19 for a full demonstration of this).

Download Setup: Alternatively, downloading the compiled zip provides you with ready-to-use css/ and js/ folders which you can link locally like <link href="css/bootstrap.min.css" rel="stylesheet">.

2. Bootstrap Structure and Files

Exercise 2.1: Directory Structure

CSS Folder

Contains compiled CSS files (e.g., bootstrap.min.css). It includes all styling rules for grid, typography, components, and utilities.

JS Folder

Contains compiled JavaScript (e.g., bootstrap.bundle.min.js). The "bundle" version is recommended because it includes Popper.js, which is required for dropdowns, tooltips, and popovers.

Icons

Bootstrap Icons is a separate library. It can be included via CDN or installed via npm. It provides SVGs or web fonts for scalable iconography.

Exercise 2.2: Include JS Plugins

The bootstrap.bundle.min.js is included at the bottom of this page. This allows interactive components (like modals in Exercise 18) to function without needing jQuery, as Bootstrap 5 uses vanilla JavaScript.
