Exercise 19: Sass Setup & Customization

1. Npm Setup

This project was set up by running npm init -y, then npm install bootstrap sass. The source code is in the node_modules folder.

2. Variable Overrides

In our scss/custom.scss, we changed the $primary color to purple and increased the $border-radius to 1rem.
